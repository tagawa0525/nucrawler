# 一覧から記事を外す条件を、使う人に見える条件にする

## 背景

2026-10-02、トップの 👁（既読で絞る）を切り替えても表示が変わらない、という報告があった。調べると 👁 自体は
正しく動いていた。最低点 50 の一覧が 3 状態とも空だったのは、表に出ていない次の規則が重なっていたため。

- 推薦点 50 以上の未読が無い（一番高い未読は 48 点）ので、「未読だけ」は空
- 50 点以上の既読（例：83 点）は、同じ報道のグループのほかの記事に ★2 が付いていて、グループごと隠れていた。
  カードに出るその記事自身は ★3 で、後から付けた評価も ★3 だった

画面には「新しい記事はありません」としか出ず、何が記事を隠しているのか、どう変えれば出るのかが分からなかった。

一覧から記事を外す条件のうち、バーで見えて操作できるのは 点数・★・👁・🔖 だけで、ほかに次の規則が裏にある。

| 規則                      | 外れる記事                               | 使う人から見た問題                                                                                                       |
| ------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| A. 低評価を隠す           | ★1〜2 を付けた記事                       | バーの ★ は「絞らない」なのに隠れている。出すには、関係の無い点数を 00 にする必要がある                                  |
| B. 低評価のグループを隠す | グループのどれかに ★1〜2 がある記事      | カードに出る記事は ★3 なのに隠れる                                                                                       |
| C. 既読のグループ         | グループのどれかが既読なら既読として扱う | カードの 👁 は記事自身の既読を出すので、「既読だけ」に 👁 の付いていないカードが出る。戻るボタンで戻るとそのカードが消える |

## 使う人がしたいこと

- **毎日の確認**：トップを開いて、まだ読んでいない、関心のありそうな新着を順に片付ける。関心が無いと評価した記事や、
  もう読んだ話は出てきてほしくない
- **集めたものを見返す**：ブックマーク（後で読む）や、高く評価した記事を、いつのものでも見返す
- **探す**：語・トピック・期間などで全期間から探す（🔍 検索）
- **出てこない理由を知る**：記事が出ないとき、どの条件で外れているかが分かり、その場で外せる

## 決めたこと

### 外れる条件は、すべてバーに出る

裏の規則 A・B はやめ、「関心が無いと評価した記事を隠す」をバーの ★ の選択肢として持つ。点数・★・👁・🔖 の
それぞれは自分の条件だけを表し、ほかの部品の意味を変えない（点数の 00 は点数で絞らないだけで、A・B を解く役は
持たない）。

### ★ の選択肢

| 選択肢（開いたとき） | 閉じたとき | 意味                                                  |
| -------------------- | ---------- | ----------------------------------------------------- |
| 絞らない             | ★          | 評価で絞らない                                        |
| ★1〜2 を隠す         | ★3+☆       | 関心が無い（★1〜2）と評価した記事を隠す。未評価は出す |
| ★1 以上 〜 ★5        | ★N         | 評価を付けた記事のうち ★N 以上（今と同じ）            |
| 未評価だけ           | ☆          | 評価の無い記事（今と同じ）                            |

- トップの既定は「★1〜2 を隠す」。今の A と同じく ★1〜2 を付けた記事を隠し、その条件がバーに見える。
  B をやめるので、自分は ★3 以上か未評価で、同じグループのほかの記事に ★1〜2 がある記事は、今と違って出る。
  フィード・JSON の一覧・MCP の既定も同じ条件にする
- 評価の意味（計画 003）は ★1〜2 が関心なし、★3 が中立、★4〜5 が関心あり。「隠す」が要るのは関心なしだけなので、
  未評価を含む選択肢はこの 1 つにし、選択肢を増やさない
- まとめたカードでは、カードに出ている記事自身の評価で判定する（B はやめる）。見えている星と判定が一致する

### 見返すときは、今のとおり全期間の画面にする

🔖（ブックマーク中だけ）や ★N（評価した記事）は、「いつのものでも見返したい」集まりなので、今のとおり全期間から
出す画面にする。トップに残すと、一覧の期間（既定 7 日）より前のブックマークや評価した記事が出てこない。
「★1〜2 を隠す」は毎日の確認のための条件なので、選んでもトップの一覧のまま（前回から・確認枠も出す）。

全期間の画面に移ったことが分かるよう、見出しに範囲を出す（例：「ブックマーク中（全期間）12 件」）。

### 既読は報道のグループ単位で、見た目と操作もそろえる（C）

既読は「この話をもう読んだ」という印で、別のソースから同じ話が届いても読み直す必要は無い（計画 007）。
絞り込みはグループ単位のまま、使う人に見える 👁 もそれに合わせる。

- カードの 👁 は、グループのどれかが既読なら付いた状態で出す
- カードで既読を外すと、その話をもう一度一覧に戻したい意図なので、グループの記事すべての既読を外す
  （記事 1 件だけ外しても、話は既読のままで一覧に戻らない）

### 記事が出ないときは、効いている条件を出す

欄が空のときや、条件で隠れた記事があるときは、効いている条件と、隠れている件数をその場に出す
（例：「点数 50 以上・未読だけ・★1〜2 を隠す に合う記事はありません。点数 50 未満の未読が 32 件あります」）。
条件を外すリンクも添え、バーを探さなくても出せるようにする。

### 確認枠

確認枠は今のとおり残す。確認枠の記事にも、一覧と同じく 👁・🔖・★ の条件を掛ける（確認枠の記事は未評価なので、
「★1〜2 を隠す」では残る）。

## 残すもの

- 軽水炉と無関係な記事を隠す規則。プロファイルのある利用者では、関係の無い記事は採点されない（`pending_score`）ので、
  点数の条件そのものから外れる。裏の規則として効くのは、プロファイルが無く点数の無い利用者だけで、その利用者の一覧を
  どうするかと一緒に別に決める
- 既読の付き方（詳細・全文和訳を開いたら既読。評価では既読にしない）
